# Simulador Brasileirão + Copas 2026

## Arquivos
- `index.html`: página editável.
- `css/style.css`: aparência e layout.
- `js/app.js`: lógica da simulação e confrontos pendentes.
- `simulador-original.html`: cópia intacta do HTML que recebemos antes desta atualização.

## Como usar
Extraia o ZIP e abra `index.html` no Chrome ou Edge. Para editar, abra a pasta no Visual Studio Code ou Visual Studio.

## Rodadas incluídas
A classificação inicial reflete os jogos concluídos até a referência de 19/10/2026. O simulador oferece as partidas pendentes da rodada 21 (Chapecoense x Vasco), da rodada 31 (Corinthians x Vitória) e as rodadas 32 a 38 para inserir placares hipotéticos. Isso evita contar os resultados já encerrados duas vezes. Os confrontos e datas das rodadas finais foram conferidos em calendário publicado; datas/horários podem ser alterados pela CBF.

## Limitação importante
As rodadas 1 a 30 não são apresentadas individualmente com placares editáveis, porque seus resultados já estão incorporados à classificação-base. O simulador se concentra nos jogos que ainda podem alterar a tabela. A projeção das vagas continentais continua sendo uma estimativa e deve ser validada separadamente contra o regulamento oficial da CBF/CONMEBOL.
